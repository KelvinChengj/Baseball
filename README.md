# 紅不讓棒球

一到兩個人都能玩的網頁棒球小遊戲。站在捕手後方看著球飛進來，抓好時機揮棒，把球打出全壘打牆。

- 純 HTML／CSS／JavaScript，不需要安裝任何東西，也不用建置
- 鍵盤、滑鼠、觸控都能玩，手機橫放或直放都可以
- 音效全部用 WebAudio 即時合成，沒有音檔

## 怎麼開始玩

直接用瀏覽器打開 `index.html` 就可以玩。

想放到網路上和朋友一起玩：到 GitHub 這個 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**、分支選 `main`、資料夾選 `/ (root)`，存檔後過一兩分鐘就會有網址。

## 遊戲模式

| 模式 | 1 人 | 2 人 |
| --- | --- | --- |
| 對戰賽（1／3／5 局） | 你是先攻的客隊對電腦。輪到電腦進攻時換你投球，或選「電腦代投」直接快轉 | 1P 先攻、2P 後攻，輪到防守的人投球；也可以選「電腦代投」，兩人只負責打擊 |
| 全壘打大賽 | 打 10 球，只算飛出全壘打牆的球，會記錄你的最佳成績 | 兩人輪流各打 10 球，全壘打多的贏，一樣多就比最遠的一支 |

難度（簡單／普通／困難）會影響球速、打擊圈大小，以及電腦投手和打者的實力。

## 操作

### 打擊

移動打擊圈對準來球，球進到本壘板時揮棒。

| | 移動打擊圈 | 揮棒 |
| --- | --- | --- |
| 1P 鍵盤 | `W` `A` `S` `D` | `F` 或 `空白鍵` |
| 2P 鍵盤 | 方向鍵 | `Enter` |
| 滑鼠 | 移動滑鼠 | 點一下 |
| 觸控 | — | 球到的時候直接點球的位置 |

一個人玩的時候，兩組按鍵都可以用。

小技巧：

- **時機**決定方向：揮早了會拉打到左外野，揮晚了會推打到右外野，差太多就是界外球。
- **上下位置**決定仰角：打擊圈稍微放在球的下方，比較容易打出高飛球和全壘打；放在球的上方會變成滾地球。
- 打到球的邊緣容易擦棒或打出軟弱的高飛球。

### 投球（對電腦）

1. 按 `1`～`4`（或 `Q`／`E`、點按鈕）選球種：直球、滑球、曲球、變速球
2. 用方向鍵、滑鼠或手指移動捕手手套，決定進壘點
3. 按揮棒鍵或「投球」按鈕

### 投球（兩人用鍵盤對戰）

打者看不到你選了什麼球：

1. 按住方向鍵再按投球鍵（1P 是 `F`、2P 是 `Enter`）選球種：`↑` 直球、`→` 滑球、`↓` 曲球、`←` 變速球，不按方向就是直球
2. 抬腿投球的時候按住方向鍵決定進壘點（九宮格），不按就是正中間

1P 的方向鍵是 `W` `A` `S` `D`。

### 其他

- `Esc` 或 `P` 暫停
- 擊出去之後，按揮棒鍵或點畫面可以快轉守備動畫

## 檔案結構

```
index.html        頁面、選單與計分板
style.css         夜間球場計分板的外觀
js/core.js        規則、投球與擊球物理、守備跑壘、電腦 AI（不碰畫面，可以單獨測試）
js/game.js        Canvas 畫面、鍵盤／滑鼠／觸控、音效、比賽流程
tests/            core.js 的測試
```

座標單位是公尺：本壘板是原點，`+y` 朝中外野、`+x` 朝一壘。全壘打牆左右兩側 97 公尺、中外野 118 公尺。

想調整手感可以改這些地方：

- 球種的球速與變化：`js/core.js` 的 `PITCHES`
- 揮棒的判定寬鬆度、打擊圈大小：`js/core.js` 的 `SWING`
- 各難度的電腦實力：`js/core.js` 的 `LEVELS`
- 打擊圈移動速度、動畫速度：`js/game.js` 開頭的常數

## 測試

需要 Node.js 18 以上：

```bash
npm test
```

測試涵蓋好壞球與保送推進、換局、再見安打、延長賽和局、全壘打大賽規則、投球軌跡、揮棒判定，以及上百場電腦對電腦的模擬比賽都能正常結束、人數與比分守恆。
